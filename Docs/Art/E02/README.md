# Рисунки моделей второй эпохи

Дата: 11 октября 2026 года. Созданы встроенным инструментом `image_gen.imagegen` по [проекту контента E02](../../era-02-neolithic-content-ru.md).

Пять итоговых листов содержат **26 концептов**: 9 построек/вариантов, 2 юнита, 8 профессий, 6 клеточных улучшений и 1 чудо. Это растровые референсы для будущих 3D-моделей и анимаций; meshes, prefabs и игровые сцены этим набором не изменены.

| Лист | Содержимое |
| --- | --- |
| [Постройки](e02-buildings-v1.png) | Длинный дом, плотницкая, ткацкая, круг совета, святилище, палисад, камень памяти, варианты амбара и гончарной |
| [Юниты](e02-units-v1.png) | Копейщик: передний/задний вид и удар; лодка: корпус и посадка пассажира с гребцом |
| [Жители — итоговый вариант](e02-residents-v2.png) | Фермер, пастух, гончар, плотник, ткач, добытчик глины, старейшина, хранитель |
| [Ресурсы и улучшения](e02-tiles-v1.png) | Поле, пастбище, глина, лён, лесная делянка, орошение |
| [Священная роща](e02-sacred-grove-v1.png) | Одногексовое чудо: деревья, площадка, ограда, резные столбы, знаки и собрание |

В качестве художественных референсов использованы собственные кадры текущей галереи: `TestResults/DetailedModelsFinal/buildings.png`, `shepherd-detail.png`, `forest-detail.png`. Сохраняются изометрия, зелёные гексы, дерево, солома, глина, камень и спокойные цвета; геометрия будущих моделей должна передавать конструкцию и рабочий реквизит.

Инструменты для этого сегмента — каменные и деревянные. Итоговый лист клеток исправляет металлический вид лопаты/топора; итоговый лист жителей уточняет каменный топор плотника и деревянную лопату. Все инструменты нужно отдельно проверить при моделировании, а не автоматически считать материал по цвету рисунка.

[Реестр моделей](asset-list.json) связывает 26 концептов с листом и позицией. Строка/столбец считаются сверху слева с единицы. Имена новых визуальных ID предварительные; существующие производственные ID сохраняются.

[Полный набор промптов](prompts.json) содержит исходные запросы и два исправления. Использован встроенный imagegen; изображения имеют непрозрачный тёмный фон и предназначены для концептов, а не для импорта как готовые игровые текстуры.

Для внедрения: создать отдельные 3D-модели и реквизит в общей библиотеке игры/галереи; сохранить одно экономическое рабочее место на жителя; подготовить действия, LOD и корректное размещение на гексе. Поля не требуют густого дополнительного мелкого декора; стадные модели и слушатели не умножают доход.
