# Проект в GitHub

Локальный репозиторий расположен в корне Unity-проекта; основная ветка — `main`. Сохраняются Assets с `.meta`, Packages, ProjectSettings, документация и генераторы моделей. Library, Temp, Logs, TestResults, сборки и локальные инструменты исключены.

Три самых крупных исходных модели местности хранятся через Git LFS. После клонирования проекта выполните `git lfs pull`, если клиент не загрузил модели автоматически. Затем откройте проект в Unity 6000.6.4f1. Сборки создаются через меню **Истоки → Разработка → Собрать игру и галерею**.

Официальный GitHub CLI установлен в отдельной локальной папке `Tools/GitHub/cli/bin/gh.exe`. Эта папка не отправляется в репозиторий. Вход выполняется через `gh auth login --hostname github.com --git-protocol https --web` и страницу GitHub с одноразовым кодом. Сохранённая авторизация используется на этом компьютере между сеансами; пароль и код подтверждения вводятся непосредственно на сайте GitHub.

Вход ещё должен подтвердить владелец аккаунта. Удалённый репозиторий и публикация подготавливаются после успешной авторизации и определения целевого репозитория. Локальная подготовка сама по себе не означает, что файлы уже загружены в GitHub.
