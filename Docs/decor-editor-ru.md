# Модели и количество декора

В `DevelopmentGallery.unity` и её Windows-сборке **E** открывает параметры клетки. Кнопка **6 — Модели** показывает 51 модель из библиотеки. Нажатие названия модели в параметрах открывает её крупным планом. Стрелки рядом с названием биома переключают его параметры и образец клетки. Камера сохраняет изометрический угол.

Каждая строка задаёт модель и минимум/максимум **экземпляров на одну клетку**. Например, `stone_Granite: 2–5` случайно размещает от двух до пяти гранитных камней на каждом гексе этого биома. `0–0` выключает модель. Одинаковые числа задают точное количество. Можно удалить строку или добавить любую модель из каталога; поиск понимает русское название и технический идентификатор.

**Применить** обновляет клетки и уже открытый полный мир в галерее. **Сохранить для игры** также записывает `Assets/Resources/TerrainDecorProfile.json`; следующая новая игра читает этот файл. Пересборка не перезаписывает пользовательский профиль. В отдельно перенесённой сборке профиль записывается рядом с exe. **Загрузить сохранённые** возвращает записанные параметры.

Каждый камень, пучок травы, цветок, дерево и кактус — отдельный экземпляр префаба со случайным положением, поворотом 0–360° и масштабом 0,5–1,5 по умолчанию. На разных гексах раскладки различаются. Seed декора позволяет воспроизвести размещение; он не меняет генерацию мира и игровые броски. Общие исходные меши моделей переиспользуются, **декор не объединяется в общий меш клетки**. Каждый экземпляр имеет собственные три уровня детализации; поддерживающий это материал использует GPU instancing.

Дюны, подъёмы холмов и горные пики остаются частью исходного рельефа. Панель показывает их отдельно от количества моделей. Вода сохраняет лёгкое движение шейдером. В игровых ресурсах и персонажах используются прежние игровые модели; параметры здесь отвечают за природный декор.

## Текущая плотность

Мелкие детали сокращены по последней просьбе пользователя; прежние 150–250 больше не задают плотность игрового мира. Подробные исходные витрины сохранены отдельно для сравнения.

| Лес | 14 | 4 дерева | Исходная поверхность |
| Луг | 15 | 0 | Исходная поверхность |
| Равнина | 14 | 0 | Исходная поверхность |
| Холмы | 10 | 3 скалы | Два подъёма |

| Побережье | 10 | 0 | Берег и вода |
| Океан | 0 | 0 | Движущаяся вода |
| Болото | 15 | 0 | Водные участки |
| Снежная тундра | 9 | 36 хвойных | Снег |

Каталог: `Assets/Resources/DecorModelCatalog.asset`; отдельные префабы: `Assets/Art/Decor/Generated/Prefabs`.

Идентификаторы: `oak_1..3`, `birch_1..3`, `pine_1..3`, `snow_0..2`; `grass`, `dry_grass`, `flower_0..4`; восемь форм `stone_` и `outcrop_` с суффиксами `Rounded`, `FlatShale`, `Elongated`, `Angular`, `Cluster`, `SplitBasalt`, `LayeredSlate`, `Granite`; `cactus_0..2`, `clover`, `shrub`, `dry_shrub`, `seed_heads`, `twig`, `shell`, `fern`, `stump`, `fallen_log`, `mushrooms`, `reeds`, `moss`, `lichen`.

Проверка `-decor-smoke <папка>` проверяет отдельные экземпляры, общие исходные меши, случайные раскладки, редактирование диапазона, обновление всех 560 гексов и сохранение JSON без изменения пользовательского профиля. `-gallery-capture <папка>` сохраняет все шесть вкладок и крупные планы биомов. Игровой цикл проверяется отдельным `-origins-smoke <папка>`.

Изменения касаются графики и инструмента разработки. Правила OpenSpec не изменены.
