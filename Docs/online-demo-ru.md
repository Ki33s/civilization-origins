# Онлайн-демка «Истоки»

Два человека играют в одной браузерной Unity-сборке, каждый управляет своим племенем. Создатель комнаты отправляет другу ссылку с кодом комнаты; доступ к своему месту сохраняется в браузере. Перезагрузка страницы возвращает игрока к его племени. Третье место отсутствует.

## Общий ход

Исследования, культура, казна, городское производство, приказы и разведанные клетки принадлежат каждому племени отдельно. Мир, реки, освоение, дороги и уникальность чудес общие. Золотые и синие знамёна различают племена. Чужие города и отряды отображаются только на разведанных вами клетках; собственные приказы не показываются второму игроку во время планирования.

Кнопка завершения хода отправляет план на сервер. До готовности друга можно снять готовность и изменить план. Когда готовы оба, сервер проверяет владение объектами, карточки, стоимость открытий и допустимость приказов, затем разрешает движение и экономику обоих племён вместе. Повтор запроса после потери связи не исполняет ход дважды. Таймера и автоматического проигрыша при отключении нет.

Сервер использует **те же файлы правил C#**, что и Unity, без второй реализации экономики на JavaScript. Подтверждённые ходы сохраняются вместе с зерном карты и контрольной суммой состояния. Клиент воспроизводит подтверждённые ходы; если результат отличается, пытается восстановить партию с сервера и сообщает ошибку, если проверка снова не прошла.

## Размещение

`Online/Server` — ASP.NET Core 8, PostgreSQL, Docker и сайт с WebGL-сборкой. `render.yaml` задаёт сервер и базу только на тарифе **Free**, в одном регионе. Браузерная сборка создаётся в Unity через **Истоки → Онлайн → Собрать браузерную игру**. После сборки локальный сайт запускается командой `dotnet run --project Online/Server/Origins.Server.csproj -c Release`, адрес `http://localhost:5080`.

На Render требуется `DATABASE_URL`: без базы сервер намеренно не запускается, чтобы не потерять партии после засыпания или перезапуска. Для локальной проверки вместо базы используется папка `Online/Server/data`, исключённая из Git. Секрет подключения хранится в Render, не в репозитории.

Бесплатный сервер Render засыпает после 15 минут без обращений. Бесплатная PostgreSQL Render действует **30 дней**. Кнопка **Сохранить партию** скачивает подтверждённые ходы в JSON; **Загрузить сохранение** создаёт новую комнату с той же партией. Сохранение не содержит токенов доступа. Перед окончанием срока базы сохранения нужно экспортировать и перенести в постоянное хранилище; платный тариф автоматически не включается.

Для загрузки в Render используется отдельный приватный репозиторий `Ki33s/civilization-origins-online`, содержащий сервер, копию общих правил, два каталога данных и готовые файлы WebGL. Полный Unity-проект остаётся в `Ki33s/civilization-origins`. Разрешение GitHub App Render ограничивается репозиторием онлайн-версии.

## Браузерная сборка для itch.io

После сборки WebGL выполните `./Online/package-itch.ps1`: готовый архив — `Builds/Origins-itch-webgl.zip`, распакованная игра — `Builds/WebGLItch`. `index.html` лежит в корне ZIP; файлы Unity используют относительные пути, окно подстраивается под размер экрана. Сжатие Gzip с decompression fallback работает без специальных заголовков сервера. Локальный просмотр: `node Online/preview-webgl.mjs`, затем `http://localhost:5081/WebGLItch/index.html`.

Без адреса сервера архив запускает одиночную демку; онлайн-кнопки отключены с объяснением. Когда Render будет развёрнут, упаковка `./Online/package-itch.ps1 -ServerUrl https://<ваш-сервис>.onrender.com` подключит онлайн, без повторной компиляции Unity. `server-config.js` содержит публичный адрес, без секретов. На Render задайте `CLIENT_ORIGINS` равным фактическому origin HTML-игры на CDN itch.io; несколько адресов разделяются запятыми. Сервер разрешает внешние запросы только с этих адресов. Приглашения сохраняют путь до игры, чтобы вход и перезагрузка работали в подкаталоге CDN.

На itch.io выберите **HTML Game**, загрузите ZIP и отметьте **This file will be played in the browser**; рекомендуемый режим — **Click to launch in fullscreen**, с **Click to Play**. Не включайте Mobile Friendly: управление рассчитано на мышь и клавиатуру. Публикация на itch.io пока отложена по просьбе пользователя. Требования к архиву проверяются упаковщиком по [документации itch.io](https://itch.io/docs/creators/html5).

## Упрощения демки относительно полной игры

- Два человеческих племени; без подбора соперников, ИИ и драфта цивилизаций.
- Начальные долины выбираются на существующей связной суше, достаточно далеко друг от друга. Полная система балансировки стартов пока отсутствует.
- Сохраняется текущая ранняя эпоха: развитие поселений и исследование мира. Бой, дипломатия и межгосударственная торговля ещё не реализованы.
- Нет нового ограничения в 48 ходов, рейтинга и придуманного условия победы. Партия продолжает текущую демку без искусственного финала.
- Это игра с приглашённым другом: интерфейс скрывает чужие планы и туман войны, но подтверждённая история передаётся обоим клиентам. Защита от извлечения скрытых данных модифицированным клиентом для соревновательных матчей потребует отдельных представлений состояния на сервере.
- Мобильное управление не реализовано; нужен компьютер с клавиатурой, мышью и браузером с WebGL.

Исходный OpenSpec не изменён. Сетевой режим расширяет первый вертикальный срез отдельным этапом.
